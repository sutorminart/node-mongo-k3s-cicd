### 1. Установка CRD (Custom Resource Definitions)
Устанавливаем определения ресурсов отдельным шагом, чтобы избежать ошибки http2: client connection lost на слабых серверах.

### 2. Установка основного стека
Используем файл конфигурации infra/monitoring-values.yaml (см. репозиторий) для настройки Ingress и таймзоны.

🔐 Доступ к Grafana
Получение пароля администратора
Логин по умолчанию: admin. Пароль генерируется автоматически при установке.

Вход через Ingress
Если настроен DNS и Ingress, Графана доступна по адресу: https://grafana.куплюземлю.рф (Punycode: xn--...)

Вход через Port-Forward (Локально)
Если внешний доступ закрыт, можно пробросить порт:
Адрес: http://localhost:8080

📈 Ключевые Дашборды
В Grafana предустановлены дашборды. Для анализа производительности используйте:

Node Exporter / Nodes:
Общая нагрузка на "железо" сервера (CPU, Память, Диск).

Kubernetes / Compute Resources / Namespace (Pods):
Выберите namespace default.
Показывает потребление ресурсов конкретными подами (arenda-app, mongodb).
